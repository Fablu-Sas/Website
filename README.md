# Fablu website

Simple bilingual static website for Fablu SAS, designed for GitHub Pages.

## Deploy on GitHub Pages

1. Create a GitHub repository, for example `fablu-site`.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

The site is pure HTML/CSS/JavaScript and requires no build step.
